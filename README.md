# よさこい写真帖

よさこい演者ひとりの写真を共有する、GitHub Pages 用の静的サイトです。写真一覧・拡大表示・元画像の個別保存・全写真の ZIP 保存に対応します。管理者はサイト内の「写真を追加」から複数枚を登録できます。

スマートフォン・タブレット・PCの画面幅に合わせて表示が変わります。提供された `assets/img_ponponsuki.png` はヘッダー、メインビジュアル、ファビコンに使用しています。画像を変更する場合は同じ場所のファイルを差し替えてください。

## 公開まで

1. GitHub に公開リポジトリを作成します。例：`yosakoi-gallery`。
2. このフォルダの**中身すべて**をリポジトリの `main` ブランチ直下に入れます。`index.html` がルートにある状態にしてください。`.nojekyll` と `photos/`・`thumbnails/` 内の `.gitkeep` も含めます。
3. `site-config.js` の `performer` を演者名に変更し、必要なら `title` と `description` も変更します。
4. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、`main`、`/(root)` を選んで保存します。
5. 公開URLは通常 `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

このURLであればアップロード先のユーザー名とリポジトリ名を自動判定します。独自ドメインや異なるURLを使う場合は、`site-config.js` の `owner`、`repo`、`branch` を設定してください。

## 写真を追加する

1. GitHub の **Settings → Developer settings → Personal access tokens → Fine-grained tokens** でトークンを作成します。対象はこのリポジトリだけに絞り、**Repository permissions → Contents: Read and write** を与えます。期限を設定してください。
2. 公開サイトの「写真を追加」を開き、JPEG・PNG・WebP の写真を選択します。1回30枚まで、1枚25MBまでです。
3. イベント名と撮影日は任意です。トークンを入力し、「写真を登録」を押します。
4. GitHub Pages の反映を待ち、ページを再読み込みします。

トークンはブラウザー内でGitHub APIの呼び出しに使い、サイトのファイルやブラウザーの保存領域には記録しません。サイトを編集できる人にだけトークンを渡してください。送信前には、公開サイトのURLを確認してください。

アップロード時には元画像をそのまま保存し、一覧用の小さなJPEGサムネイルを作ります。写真とサムネイル、`data/photos.json` は一つのGitHubコミットとして更新されます。2人が同時に追加して衝突した場合は、画面を再読み込みして再度登録してください。

## 公開範囲と容量

- この構成のGitHub Pagesは公開サイトです。URLを知る人以外にも閲覧可能で、リポジトリ内の写真も公開されます。閲覧者を関係者に限定する用途には、そのままでは使えません。
- 元画像のEXIFなどのメタデータも残ります。公開前に写っている人の了承や位置情報の扱いを確認してください。
- GitHub Pages の公開サイトには容量制限があり、ソースリポジトリも約1GB以下が推奨されています。写真が多い、または高解像度写真を大量に保存する場合は画像保存先を別サービスにする構成が向いています。
- ZIPは閲覧者のブラウザーで作るため、大量の写真ではメモリが不足する場合があります。ZIP内のJPEGやPNGは再圧縮せず元画像を収録します。
- Gitの履歴に残った写真は、一覧から消しただけでは完全には消去できません。誤って公開した写真がある場合はリポジトリの履歴も含めて対応してください。

## ローカル確認

このフォルダで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。ローカルURLでは保存先を自動判定できないので、アップロード操作を確認する場合は `site-config.js` に `owner` と `repo` を設定してください。

依存パッケージやビルドは不要です。
